# BIM/CAD Readiness Notes

Public URL:

https://www.vishomecarpet.com/resources/bim-cad

First-stage verified asset types:

- Product image and texture references
- PDF pattern references where available
- Product specification JSON based on verified fields
- CAD pattern files only if real files exist

Do not create or submit Revit, Archicad, SketchUp or IFC files unless prepared and verified by a qualified BIM service provider.

Manual confirmation required:

- CONFIRM_BIM_PLATFORM_REQUIREMENTS
- CONFIRM_CAD_PATTERN_FILES
- CONFIRM_REVIT_SERVICE_PROVIDER
- CONFIRM_PRODUCT_METADATA_FOR_BIM
